# Hi there, I'm rizzhold! 👋

> An Indonesian SMK RPL student exploring the digital universe, one line of code at a time.

I'm a software engineering student based in Indonesia, currently diving deep into **Rekayasa Perangkat Lunak (RPL)**. I love building things, breaking them to see how they work, and constantly exploring new tech—from web development and Android to linguistics, automation, and open source.

I believe the best way to learn is by building. That's why I create personal playgrounds instead of just standard portfolios.

- 🌍 Learning how language, automation, and open-source tools shape our digital lives.
